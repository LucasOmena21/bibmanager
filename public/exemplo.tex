Este é um documento de exemplo para demonstrar o filtro do BibManager.
As chaves usadas nos comandos \verb|\cite{}| abaixo serão extraídas
e usadas para filtrar seu arquivo \texttt{.bib}.

\section{Conclusão}

e use este arquivo no filtro do BibManager.
